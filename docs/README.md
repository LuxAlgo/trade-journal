# Trade Journal Documentation

This directory holds product design and behavior documentation. Stable product rules
are maintained in the corresponding document; implementation progress is tracked in
`tasks.md` at the repository root.

| Document                                       | Description                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [i18n.md](i18n.md)                             | **Authoritative entry point for the internationalization behavior contract and the new-copy workflow**: seven-locale identifiers and switching rules, message file layout and namespace ownership, language boundaries for errors/imports/AI/voice/export, formatting boundaries, testing conventions, the seven-language glossary, and the copy/test inventory. |
| [ai-scope.md](ai-scope.md)                     | Account scoping and filter boundaries for AI features (ask/recap/critique/AI import).                                                                                                                                                                                                                                                                            |
| [calendar-insights.md](calendar-insights.md)   | Definitions and computation rules for calendar performance insights.                                                                                                                                                                                                                                                                                             |
| [design.md](design.md)                         | Design principles, including readability rules such as P&L never conveyed by color alone.                                                                                                                                                                                                                                                                        |
| [edge-score.md](edge-score.md)                 | Composition and computation of the Edge Score (v2).                                                                                                                                                                                                                                                                                                              |
| [importers.md](importers.md)                   | Broker/platform CSV/HTML importers: supported formats, detection rules, and timezone handling.                                                                                                                                                                                                                                                                   |
| [market-data.md](market-data.md)               | Historical market data: provider connections, caching, and estimation rules.                                                                                                                                                                                                                                                                                     |
| [performance-trends.md](performance-trends.md) | Computation and presentation rules for performance trends analysis.                                                                                                                                                                                                                                                                                              |
| [prop-firms.md](prop-firms.md)                 | Domain model for prop firm evaluation, cost, and payout tracking.                                                                                                                                                                                                                                                                                                |
| [trade-explorer.md](trade-explorer.md)         | Trade list (Trade Explorer) filtering, sorting, and bulk actions.                                                                                                                                                                                                                                                                                                |
| samples/                                       | Importer sample files (demo-trades-tradingview.csv, mt5-timezone.html).                                                                                                                                                                                                                                                                                          |
